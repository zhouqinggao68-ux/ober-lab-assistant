> 基于软件版本 `PCXSJXTZ1.2.0_221025`（软件 ID `1547`）及全部 7 项子实验实机端到端验证整理（实测成绩：`100 / 100 / 98.6 / 97.53 / 98.18 / 97.02 / 94.80`）。

## 一、 软件架构（架构 B2：单进程纯 3D + 内嵌 `查看评分`）

与《精馏实训》（架构 A）和《流化床干燥》（架构 B1，`scorerun.exe` 独立进程）不同，本项目全部交互集中在单个 `UnityVR.exe` 窗口内：

- **无 `仿DCS / GUS.exe`、无 `ModelManage.exe`、无独立 `scorerun.exe`**。
- **顶部 11 按钮功能栏（`1920x1080` 下 `ry ≈ 0.0258`）**：
  `返回主页` | `实验介绍` | `文件管理` | `记录数据` | `查看图表` | `设备列表` | `查看评分` | `实验分析` | `生成报告` | `系统设置` | `退出`
- **评分审计**：点击顶部 `查看评分` 弹出全屏透明叠加层（`试卷运行界面`），左侧为 `P01..P04`，右侧为具体步骤；超过 12 步时使用 `scroll_mouse(x=1000, y=500, direction="down", notches=14)` 下翻；**严禁点击左上角 `保存成绩`**，看完后点右上角 `× (rx=0.980, ry=0.034)` 关闭。
- **交卷路径**：全部步骤与思考题完成后，在 `UnityVR.exe` 点击顶部 `退出` → 确认框点 `确定` → 等待 `10s` → 返回云平台浏览器 → 点击 `更新题目状态` → 如按钮仍为 `结束本项目` 则点击解锁后再点 `更新题目状态` 确认恢复为 `启动`。

## 二、 7 项子实验通用硬规则与避坑要点

1. **每次重开先做四项审计**：
   - 先用 `probe_desktop_environment(include_minimized=True)` 获取全新 `HWND`，进入对应实验后，先依次核对：`查看评分` (`P01..P04`)、`文件管理` 是否需切换预置文件名、`记录数据` 表头常量与全列单位（水平滚动 `y ≈ 0.70` 位置拖到底）、`设备列表` 各分类子菜单条目。
2. **空气流量调节阀为“旁路/放空调节阀”机制**：
   - 本项目所有装置中的 `空气流量调节阀` **开度 `100.00%` 时气体全部旁路放空（入塔流量 = `0`）**；关闭方向减小开度才增大入塔风量。
   - **停车防扣分铁律**：氨吸收/丙酮吸收等项目中，`P02` 通常明确要求**先将 `空气流量调节阀` 全开至 `100.00%`（或先关进口阀），再点击风机开关停风机，最后再将其关闭至 `0.00%`**，严禁跳过开旁路步骤直接停风机。
3. **调节阀弹窗调参闭环与悬停遮挡陷阱**：
   - 长按开/关按钮（`< 0.28s` 约触发 `±1%` 步进，持续按住约 `0.45s ≈ 25%`，`2.5s` 直达 `0% / 100%`）。
   - Unity 在点击 `开`/`关` 后鼠标仍停留在按钮上时，灰色悬浮提示条会直接遮挡居中显示的当前开度数值！**读取开度前务必先把光标移至弹窗黑色标题栏（`neutral_xy ≈ (rx=0.500, ry=0.397)`）**，推荐直接使用 `adjust_valve_popup` 闭环微调工具。
   - 使用 `设备列表` 菜单时，打开分类后至少等 `0.35s`，点击目标设备后至少等 `2.0s` 待 3D 镜头推拉动画完成再点选。
4. **不同实验的 `设备列表` 分类顺序会互换**：
   - 例如 CO₂ 吸收解吸中 `阀门` 在第 1 项、`开关` 在第 2 项；而 **氨吸收 / 丙酮吸收中 `开关` 在上、`阀门` 在下**。每次换实验必须先 OCR `设备列表` 子菜单，严禁跨实验硬编码菜单坐标。
5. **数据管理横滚与防输入法提交**：
   - 表格含横向滚动条（可用 `detect_ui_boxes(kind="scrollbar_thumb")` 检出滑块位置并用 `drag_mouse(button="left", duration_sec=0.45, steps=20)` 分段横拉）。
   - 所有数字格使用 `fast_type(..., clear=True, press_enter=False)` 填入，全部列核对无误后**仅点击一次 `提交`**，见 `保存成功` 弹窗后关闭。
   - 若同一物理流道存在多个并列流量计列（如 `F1/F2` 或 `F3/F4`），只填实测使用的通道列（如丙酮填 `F2` 与 `F4`），未用通道留空避免优先级冲突。

## 三、 七大子实验分项实操速查

### 项目 1–4：填料塔流体力学性能与传质系数（指导模式 / 非指导模式）
- **指导模式（项目 1 干塔 / 项目 2 湿塔 / 项目 3 传质）**：严格跟随实机 `查看评分` 步骤操作，气速校正与压降梯度 `ΔP/Z` 可用 `skills/ober-lab-assistant/scripts/chem_calc.py packed-hydro` 计算复核。
- **项目 4（`填料塔流体力学性能测定`，非指导模式）**：按先湿润填料后逐级增/减风量测压降曲线记录，完整覆盖操作段后再停车交卷。

### 项目 5：`二氧化碳吸收解吸实验`
- **`文件管理`**：切换选中 `100L水流量`。
- **操作要点**：按实机 `P01 S01..S20` 开启总电源、吸收塔与解吸塔水路（`100 L/h`）、气泵及 `CO2` 气路，稳态后记录温度 `T1..T4`、压差及浓度，执行 `P03` 提交并按 `P02 S01..S13` 顺序停车。可用 `chem_calc.py co2-absorption` 核算物性与传质单元数。

### 项目 6：`氨吸收实验`（实测 `97.02`）
- **默认常量（核自 `记录数据` 表头）**：`Z = 0.54 m`、`D = 0.10 m`、`ρ_U = 1000.0 kg/m³`、`ρ_air20 = 1.204 kg/m³`、`ρ_nh3_20 = 0.707 kg/m³`、`C_exh = 0.006313 mol/L`、`V_exh = 5.00 mL`、`C_abs = 0.05148 mol/L`。
- **`文件管理`**：选择 **`0.15氨`**（单组工况，`P01 S01..S16`、`P03 S01..S23`）。
- **操作序列**：
  1. 调水流量调节阀 `30.00%`（`30.00 L/h`）；
  2. **先全开 `空气流量调节阀` 至 `100.00%`** → 开总电源 → 开风机开关 → 调 `空气流量调节阀` 至 `90.00%`（对应 `5.83 Nm³/h`）；
  3. 开 `氨瓶阀门` `100.00%` → 调 `减压阀` 至 `18.00%`（`0.06 MPa`）→ 调 `氨流量调节阀` 至 `25.00%`（`0.15 Nm³/h`）；
  4. 记录 `U型管` 与 `T1..T4`，切开 `三通阀1` 后用 **`watch_color_endpoint(..., target_color="yellow")`** 盯住吸收瓶变黄终点，立刻关回 `三通阀1`；依次点右侧 HUD `读数` → `取样` → `滴定分析` 获取量气管与耗酸体积。
- **计算与停车**：运行 `chem_calc.py ammonia-absorption` 生成全部 23 项结果填表提交；`P02` 严格执行：`关氨瓶总阀 → 关减压阀 → 关氨调节阀 → 全开空气调节阀 (100%) → 停风机 → 关空气调节阀 (0%) → 关水调节阀 → 关总电源`。

### 项目 7：`丙酮吸收实验`（实测 `94.80`）
- **默认常量（核自 `记录数据` 表头）**：`Z = 0.700 m`、`D = 0.050 m`（`Vp = 0.001374 m³`）、`ρ_U = 1000.0 kg/m³`。
- **`文件管理`**：选择 **`104L水流量`**。
- **操作序列（`P01 S01..S08`）**：
  1. `总电源开` → 全开旁路 `空气流量调节阀` (`100.00%`)；
  2. 调 `F4流量计进口阀` 至约 `53.00%`，使 `水流量计F4 = 103.86 L/h`（接近目标 `104 L/h`）；
  3. 点开 `风机` → 全开 `F2流量计进口阀` (`100.00%`) → 调 `空气流量调节阀` 至 `59.00%`，使 `空气流量计F2 = 1.00 Nm³/h`；
  4. 读取 `U型管读数mmH2O` 与 `T1..T4` 后，点击切换 `三通阀门VA13`，待右侧 `色谱测量浓度显示` 稳定读出 `y1`、`y2`。
- **计算与停车**：运行 `chem_calc.py acetone-absorption` 计算全部 21 项数据（`V_mol_s`, `L_mol_s`, `m(T)` 查表 `25℃ -> 1.98`, `K_Ya`, `φ`），在 `记录数据` 对应 `F2 / V2 / F4` 列填表提交；`P02 S01..S06` 严格按：`全开空气调节阀 (100%) → 关F2进口阀 (0%) → 停风机 → 关空气调节阀 (0%) → 关F4进口阀 (0%) → 总电源关`。

## 四、 `实验分析`（思考题）防错提示

- 即使同类实验题库外观相似，进场作答前仍需逐屏 OCR 核对题干与选项内容；翻页勾选后推荐通过 `detect_ui_boxes(kind="radio_circles")` 复核 `checked: true` 状态再点击一次 **`提交`**。
- 完成后回 Edge 浏览器前，先检查 Edge 当前激活标签页是否为平台页面，切勿在后台标签页或错误纵坐标上盲点。
