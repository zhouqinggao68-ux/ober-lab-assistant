# 欧倍尔《流化床干燥实验 3D 仿真软件【9310】》实操 SOP 与防扣分清单

> 基于官方《流化床干燥实验仿真培训软件操作说明书》（2018 年 1 月版）及实机全流程实测校准（软件版本 `PCLHGZH2.0.0_211109`，实机终分 `95.238`，耗时 `01:06:17`）。

## 一、 软件架构识别（双进程纯 3D + 评分窗模式）

与《精馏实训装置》不同，本项目属于**架构 B（无 `仿DCS / GUS.exe`，无 `ModelManage.exe` 悬浮控制条）**：

1. **`UnityVR.exe`（`流化床干燥实验3D虚拟仿真软件`）**：负责全部 3D 场景操作、右侧称重/计时 HUD、顶部功能栏（`记录数据` / `设备列表` / `查看图表` / `实验分析` / `生成报告` / `系统设置` / `退出`）。
2. **`scorerun.exe`（`试卷运行界面`）**：独立实时评分窗，左侧分 5 个阶段展示全部评分条目（`实验准备阶段`、`流化床干燥`、`实验结束`、`数据处理`、`实验分析`）；注意云平台启动模式下其菜单栏 `退出(X)` 不可用（UIA 树仅暴露 `工具(Y)` 与 `帮助(Z)`），**严禁点击 `工具(Y)` 下的 `保存成绩`**，交卷必须通过 `UnityVR.exe` 顶部 **`退出`**。

### 默认实验参数
- 塔径：`135.0 mm`；床层高度：`150.0 mm`；加水量：`235.0 mL`
- 干燥物料：变色硅胶（`40.0` 目）；**取样空瓶重 $\omega_0$：`32.0 g`**；烘箱干燥温度：`120.0℃`；空气相对湿度：`80.0%`

## 二、 实机防踩坑硬规则

1. **进场先关 `全局标签`（防 3D 标签遮挡仪表）**：
   - 点击顶部 `系统设置`，取消勾选 `全局标签`，否则悬浮设备标签文字会直接盖住 `SWP-C40` / `SWP-D40` 数码管或按压区域。
2. **禁止直接对红字七段数码管调用普通 `ocr_window_or_roi`**：
   - `SWP-C40`（`床层温度`）与 `SWP-D40`（`进气温度`）未点亮笔段为暗红色（`R ≈ 115..140`），极易被 RapidOCR 误读或混淆 `115.0` 与 `105.0`。
   - **开加热之前，务必调用 `read_seven_segment_roi(window_query="流化床", roi=..., color="red")` 核对 `SWP-D40` 设定值（`SP`）已精确降至 `105.0℃`**（默认初始常为 `115.0℃`）；若在 `SP != 105.0` 时提前点开 `加热开关`，`LHGZ_P02_SW>0.500` 会立刻被判定 `操作过早，未按顺序操作` 并永久锁死 `0.000`。
3. **3D 阀门/开关动态提示兼容（`已打开`/`已关闭`）**：
   - 本软件部分阀门与开关悬停提示使用 **`已打开` / `已关闭`**（如 `空气旁路阀：已打开`）或中文设备前缀（`加热开关：已关`、`电源开关：已开`）。请使用升级后的 `click_3d_valve_verified` 或 `hover_and_ocr` 核对状态；`空气流量计阀门` 属于调节阀弹窗，按住 `关` / `开` 按钮需使用 `fast_click(..., press_duration_sec=0.6~1.2)` 并移开光标后复核开度数值。
4. **干燥计时器倍速与取样动画等待铁律**：
   - 右侧 HUD 计时器（`MM:SS.cc`）约为现实时间的 **6.65–6.8 倍速**（约 9 秒现实时间 = 1 分钟仿真时间）。可通过 `watch_value_threshold(..., parse_mode="mmss_minutes", ...)` 监控目标分钟数。
   - **单次取样严禁缩短延时**：点击 `物料取样器` 取样（等 `2.0s`）→ 再点一次放入称量瓶（等 `3.0s`）→ 点击 `空瓶+湿物称重`（等 `2.0s`）→ 点击 `空瓶+干物称重`（等 `2.0s`）。延时不足会导致称重读数未刷新或漏计 `LHGZ_QY_PUT`。
   - **立即逐条核验记录**：HUD 仅保留最近 5 条取样历史，且每次称重会覆盖上方 $\omega_1, \omega_2$ 数值。必须每次取样后立刻 OCR 右侧 HUD，确认 $\omega_1, \omega_2$ 均较上次变化且 $\omega_1 \ge \omega_2 > 32.0$。
   - **尽量在 `T_bed < 95.0℃` 前完成 12 次取样**：实机实测表明，床层温度 `< 95℃` 时的样本（第 1–9 组）`PD02_ESCOR` 均顺利得满 `0.500`，而升温至 `>= 95.00℃` 后的第 10–12 组在 `LHGZ_PD02_ESCOR[9..11]` 出现 `0.000`。建议前中段每 `3–5` 仿真分钟取样 1 次，在 `95℃` 之前收齐至少 12 个有效样本。

## 三、 标准操作全流程（对应 `scorerun.exe` 5 阶段）

### 阶段 1–2：流化床干燥开车与 12 点取样
1. 打开加水斗阀门（`LHGZ_V02_OP>0.500`）加入固定水量，并打开空气流量计阀门（`LHGZ_V01_OP>0.500`）通气搅拌使硅胶均匀吸水。
2. 等待加水斗水全部滴加完（`LHGZ_D02_LL<0.500`），调节空气流量至约 **`16.0 m³/h`**（阀门开度约 **`64%`**，`FI01_PV ≈ 0.25 × 开度`，`LHGZ_FI01_PV = 16.000` 占 10 分！）。
3. 关闭加水斗阀门（`LHGZ_V02_OP<0.500`）→ 打开电源开关（`LHGZ_MAIN_OP>0.500`）→ 打开空气旁路阀门（`LHGZ_D01_OPB>0.500`）。
4. 跳转 `仪表 -> 进气温度`，点击向下微调按钮将 `SWP-D40` 下排设定值调为 **`105.0℃`**，用 `read_seven_segment_roi` 复核 `105.0` 后，核对 `scorerun.exe` `LHGZ_TI01_SP=105.000` 变为 `2.000`。
5. 开启 `加热开关`（`LHGZ_P02_SW>0.500`）预热空气，**待进气温度 `SWP-D40 PV >= 95.0℃` 后**，关闭空气旁路阀（`LHGZ_D01_OPB<0.500`）。
6. 跳转 `主要设备 -> 物料取样器`，**待床层温度升至约 `38℃` 时**，执行第 1 次取样与湿/干物称重（`QY_OP` / `QY_PUT` / `QY_CZ` / `QY_DD` 各 5 分）；后续隔 `3–5` 仿真分钟连续取满 **12 次以上**，并在 `scorerun.exe` 核对 `LHGZ_QY_NC>11.000` 变为 `5.000`。

### 阶段 3：数据处理（`数据管理`，12 组 × 7 列）
- **纠正说明书第 5 页笔误**：说明书写 `Δω = ω2 - ω1` 为符号笔误，实际含水量应为正值：
  - `干燥时间(min)` = $\mathrm{MM} + \mathrm{SS.cc} / 60$（保留 2 位小数，第 1 次为 `0.00`）
  - `水分重(g)` = $\Delta\omega = \omega_1 - \omega_2$（保留 4 位小数）
  - `干物重(g)` = $\omega_2' = \omega_2 - \omega_0$（$\omega_0 = 32.0$，保留 4 位小数）
  - `含水率 × 10⁻² (kg水/kg干物)` = $\dfrac{\Delta\omega}{\omega_2'} \times 100$（保留 2 位小数，随干燥时间应单调下降）
- **四象限分批填报**：先点击弹窗内 `记录数据` 11 次生成第 1–12 行；用 `detect_ui_boxes(kind="input_boxes")` 实测每行格心；分 4 个象限（左上 1–6 行×1–5 列 → 拖垂直滚动条到底填左下 7–12 行×1–5 列 → 拖水平滚动条到右填右下 7–12 行×6–7 列 → 拖垂直滚动条到顶填右上 1–6 行×6–7 列）全部用 `fast_type(..., clear=True, press_enter=False)` 填完核对后再点一次 **`提交`**，并用 `detect_ui_boxes(kind="red_close")` 关闭 `保存成功` 弹窗与 `数据管理`。

### 阶段 4：实验分析（`思考题` 1–10 题）
- 点击顶部 `实验分析`，对照官方《操作说明书》与 `scorerun.exe -> 实验分析` 中绿色圆点与带 `(-)` 减号防错提示点，用 `detect_ui_boxes(kind="radio_circles")` 精确定位并逐页勾选全部 10 题后点击 `提交`（`实验补充与扩展` 文本框留空即可），关闭 `提交成功！` 与 `思考题` 弹窗并在 `scorerun.exe` 复核无 `0` 分漏选或误选扣分项。

### 阶段 5：严格有序冷却停车（`实验结束`）与云端交卷
1. **`LHGZ_P02_SW<0.500`**：跳转 `仪表 -> 进气温度`，点击关闭 `加热开关`，`hover_and_ocr` 确认 `加热开关：已关` 且 `scorerun.exe` 得分 `2.000`。
2. **`LHGZ_V01_OP<0.500`（未冷却严禁关风门）**：跳转 `仪表 -> 床层温度`，调用 `watch_value_threshold(window_query="流化床", roi=preset.rois["bed_temp_led_swp_c40"], led_color="red", target_op="lt", target_value=30.0, stable_samples=2, poll_interval_sec=3.0, timeout_sec=130, ensure_foreground=True)` 盯表至 **`< 30.0℃`**；随后跳转 `空气流量计阀门`，按住 `关` 按钮（`press_duration_sec=1.2`）使开度归 `0.00` 并关闭弹窗，确认 `scorerun.exe` 得 `2.000` 后再下一步。
3. **`LHGZ_MAIN_OP<0.500`**：跳转 `开关 -> 电源开关`，关闭总电源开关并 `hover_and_ocr` 确认 `电源开关：已关`。
4. **交卷退出与解锁核验**：
   - 在 `scorerun.exe` 确认 `百分制得分 >= 90` 后截图留存，切回 `UnityVR.exe` 点击顶部 **`退出`** → 在 `"退出Unity3D会导致模型客户端所有程序均退出，是否继续？"` 点 **`确定`** → 等待 10 秒。
   - 用 `probe_desktop_environment()` 确认 `UnityVR.exe` 与 `scorerun.exe` 均已退出；切回 Edge 点击 `更新题目状态`（若 `操作` 仍显示 `结束本项目` 则点击解锁后再点一次 `更新题目状态`），确认 `最高成绩 >= 90`、`上次分数 >= 90`、`上次时间 < 02:00:00` 且 `操作` 恢复为 `启动`。
